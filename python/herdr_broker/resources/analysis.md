Findings contain only material facts beyond the item answers, especially contradictions; when items is empty, report main observations there. Evidence is a list of current-screen ranges in importance order. Each focus_line lies between start_line and end_line. Use an empty anchor unless a focus line exceeds the selected evidence budget; then use a short exact anchor from that line. refs are unique 1-based indices into this evidence list, not screen line numbers. Observed or inferred answers and findings require refs; unknown answers may have none. Nonblank screens require a nonblank evidence candidate. Empty screens have none.
